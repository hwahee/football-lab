# 게임 디자인 시스템 — "Gridiron"

게임 화면(`apps/mobile/src/game`) 전용 디자인 시스템입니다. 앱의 스킨(standard/contrast/office/kids)은
설정·할 일 같은 유틸리티 화면에만 적용되고, **게임은 스킨을 따르지 않습니다.** 게임은 언제나 야간 경기장의
전광판처럼 보여야 하기 때문입니다.

구현: `apps/mobile/src/game/ui/kit.tsx` (컴포넌트), `apps/mobile/src/game/palette.ts` (색).

## 원칙

1. **야간 경기장**: 어두운 남색 배경 위에 잔디의 초록과 전광판의 호박색(LED)만 밝게.
2. **전광판 숫자**: 점수·시계·확률 같은 숫자는 고정폭 LED 호박색(`GText variant="digits"`).
3. **누르는 맛**: 버튼은 "면 + 모서리" 구조라 누르면 면이 내려갑니다(`GButton`). 그림자·블러 없음.
4. **기울어진 대문자**: 제목은 컨덴스드 굵은 이탤릭. 팀 색 막대도 같은 각도(-12°)로 기울입니다.
5. **팀 색은 하나**: 블루/레드는 필드의 선수 토큰, 엔드존, 스코어보드, 패널 강조선에서 모두 같은 값.
6. **색만으로 말하지 않기**: 선택 상태는 테두리+글자색+밑줄, 플레이 종류는 색 띠+라벨을 함께 씁니다.

## 컴포넌트

| 컴포넌트     | 용도                 | 메모                                                         |
| ------------ | -------------------- | ------------------------------------------------------------ |
| `GText`      | 모든 글자            | `display`·`title`·`label`·`body`·`small`·`digits`            |
| `GButton`    | 진행 버튼, 방향 패드 | 톤 `go`(시작) / `primary`·`danger`(팀) / `neutral`, 크기 3종 |
| `GPanel`     | 화면 아래 조작 보드  | 왼쪽 강조선 = 지금 조작하는 팀                               |
| `GSegmented` | 2~3개 중 하나 고르기 | 선택된 칸에 LED 밑줄                                         |
| `GCard`      | 플레이북의 플레이    | 왼쪽 색 띠 = 종류(런/패스/킥 …)                              |
| `GChip`      | 배치 탭의 선수       | 필드에서 선수를 눌러도 같은 칩이 선택됨                      |

앱의 디자인 시스템과 마찬가지로 **인터랙티브 컴포넌트는 `testID`가 필수**이고, 값은
`apps/mobile/src/testing/testids.ts`의 `TESTID.game`에서만 가져옵니다.

```
└───────────────────────────────┘
```
